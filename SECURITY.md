# Security policy

## Supported versions

Security fixes are applied to the latest commit on `main`. This repository does
not currently maintain older release branches.

## Reporting a vulnerability

Do **not** disclose a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting flow:

1. Open the repository's **Security** tab.
2. Select **Advisories**.
3. Select **Report a vulnerability**.

Direct link:
[Privately report a vulnerability](https://github.com/nguyentthuy11work-dev/itb-club-assets/security/advisories/new)

Include affected endpoints or components, reproduction steps, impact, and any
suggested mitigation. Remove real credentials, personal data and private asset
evidence from the report.

You should receive an acknowledgement within seven days. A fix and disclosure
timeline will be agreed based on severity and exploitability.

## Automated safeguards

The repository uses CodeQL, Gitleaks, dependency review, Dependabot and OpenSSF
Scorecard. Automated results support review but do not replace responsible
manual security analysis.
